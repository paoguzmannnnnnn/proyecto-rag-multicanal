# 🤖 Proyecto: WhatsApp RAG Multicanal (Pinecone)

Bot de WhatsApp con arquitectura **RAG (Retrieval-Augmented Generation)** usando:
- WhatsApp Cloud API
- Pinecone (vector DB)
- Hugging Face / Groq para embeddings y generación
- Soporte para ejecución local o despliegue en Render
